# Maison Vell — Runway Depth Lookbook

Single-file demo page (`index.html`), no build step, no libraries.

- Six looks stand in a line that recedes into the distance.
- Drag, scroll or use the arrow keys to bring the next look to the front.
- Product rail on the right scrolls in sync; the look number rolls at bottom left.

Images load from the sprite sheets referenced at the top of the script (`MODELS`, `PIECES`). Fonts load from Google Fonts, so an internet connection is needed.

## Preview

Open `index.html` in a browser, or view the GitHub Pages link for this repo.
